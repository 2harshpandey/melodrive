# Melodrive

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

A personal music streaming application.

## Features

- User authentication
- Personal music library for each user
- Music player with standard controls
- Song search
- Song upload

## Tech Stack

- React
- TypeScript
- Material-UI
- Cloudinary for media storage
- Netlify for deployment and serverless functions
